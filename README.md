# Dynapse 설치

Dynapse는 내가 구독하는 AI(Codex 등)로 템플릿 작업을 받아 이 기기에서 실행하는 데스크톱 앱이에요.

## 내려받기

[다운로드 페이지](./index.html)에서 내 컴퓨터에 맞는 파일을 받으세요.

- **macOS**: `.dmg`를 열고 Dynapse를 **응용 프로그램** 폴더로 옮긴 뒤 실행하세요. 다른 위치에서 실행하면 업데이트를 받을 수 없어요.
- **Windows**: `-setup.exe`를 실행하세요. 관리자 권한 없이 설치돼요.

## 업데이트

앱이 켜져 있으면 새 버전을 조용히 받아 두고, 상단에 **업데이트 준비됨**이 보여요. 누르면 다시 시작하면서 설치돼요. 작업이 실행 중일 때는 끝난 뒤에 설치할 수 있어요.

이 리포에는 업데이트 정보(JSON)만 있고, 설치 파일은 [Releases](../../releases)에 있어요.
